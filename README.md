# ИИндуизация

Расширение для Chrome и Firefox, которое смотрит Instagram Reels и YouTube Shorts вместе с вами. Как только в кадре индийский контент, начинается праздник: на экран выходит толпа танцующих 3D-персонажей, играет индийская музыка, сверху сыплются конфетти или лепестки, а за рилсом появляется улица Мумбаи или площадь в Дели.

Модель распознавания работает прямо в браузере. Видео никуда не отправляется.

Версия 0.24. В Chrome Web Store и Firefox Add-ons расширения пока нет, ставится из исходников.

## Что умеет

- Смотрит ленту в реальном времени, два кадра в секунду (интервал можно поменять). Распознаёт CLIP ViT-B/32 с дообученными головами для сцены и лиц: около 60 мс на кадр на видеокарте и около 200 мс на процессоре.
- Восемь тем праздника: болливуд, бхангра, Холи, Дивали, свадьба, крикет, улица и обычная. Изредка выпадает шоу-сюрприз.
- Толпа от 14 до 24 человек, расставленная рядами так, что видно лицо каждого. В репертуаре 41 танец: 15 уличных (хип-хоп, локинг, поппинг, крамп, вакинг, хаус), 22 смешных стиля вроде курицы, зомби и робота и 4 индийских.
- Вокруг толпы коровы, статуи богов в небе, слон и обезьяны. Между рядами ездят тук-туки и мопеды с седоками, носятся собаки. Фоном служит одна из 17 фотографий индийских городов, и люди стоят на земле снимка.
- Дообучается на вашей ленте: отметьте десяток кадров кнопками «Индус» и «Не индус», и личная модель подстроится под ваши рилсы. Обучается она тут же, в браузере.
- Может листать ленту сама: пустой рилс пролистывается через 4 секунды, на подходящем лента задерживается. Включается в настройках.
- Свои треки добавляются в плейлист командой `npm run music`.
- Качество графики настраивается под слабые и мощные машины, модель можно считать на видеокарте или на процессоре.

Автолайк тоже есть, но по умолчанию выключен.

## Приватность

- Кадры разбираются на вашем компьютере и не покидают браузер.
- При первом запуске браузер один раз скачивает веса модели с Hugging Face, до 170 МБ.
- Аналитики, рекламы и трекеров нет.
- Обмен разметкой для общего датасета выключен по умолчанию и работает, только если у сборки настроен сервер. Если включить его и подтвердить согласие, на сервер уходит числовой отпечаток кадра (512 чисел, картинку по ним не восстановить) и ваша метка. Кадры, ссылки и данные аккаунта не отправляются. Отправленное удаляется кнопкой в настройках.

## Установка

Понадобятся curl, ffmpeg и Node.js.

```bash
git clone https://github.com/DJpopusk/iinduization.git
cd iinduization
./scripts/fetch-assets.sh
```

Скрипт скачает three.js, transformers.js и музыку.

### Chrome

Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.

### Firefox 140 и новее

Соберите вариант для Firefox командой `./scripts/build-firefox.sh`. Затем откройте `about:debugging`, раздел «Этот Firefox», нажмите «Загрузить временное дополнение» и выберите `dist/firefox/manifest.json`.

### Дальше

Откройте `instagram.com/reels/` или `youtube.com/shorts/` и листайте.

3D-модели персонажей в репозиторий не входят, у них свои лицензии. Без них танцуют манекены, остальное работает так же.

## Для разработчиков

| Где | Что |
|---|---|
| `extension/content.js` | следит за лентой и отправляет кадры на оценку |
| `extension/background.js`, `extension/iindus.worker.js` | модель распознавания |
| `extension/overlay.js` | 3D-сцена праздника на three.js |
| `extension/popup.*` | настройки |
| `scripts/` | загрузка ассетов, сборка, танцы, список авторов |
| `server/` | сервер общего датасета (Cloudflare Workers и D1) |
| `training/` | обучение модели |

Тесты гоняют расширение в настоящем Chromium на подставной ленте из восьми рилсов:

```bash
npm install && npx playwright install chromium
test/e2e/make-videos.sh
npm test
```

Архив для Chrome Web Store собирает `scripts/pack.sh`.
